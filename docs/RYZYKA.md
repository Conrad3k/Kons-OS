# Znane ograniczenia i ryzyka K1

Zasada (SPEC §2.5): mechanizm bezpieczeństwa to nie gwarancja. Tu zapisujemy, czego system
**jeszcze nie chroni** albo **nie może chronić**, i kiedy planujemy to zmienić.
Stan na wersję 0.4.0 (koniec M4). Klasyfikacja: **W** — wysokie, **Ś** — średnie, **N** — niskie.

Bez Secure Boot (wersje deweloperskie, SB wyłączony) zostaje dm-verity (zmiana bajtu = zatrzymanie), ale cały `k1.efi` można podmienić. | N | podpisany `k1.efi` (test `sb-zmieniony`), `noinitrd` + wbudowana linia poleceń (obcy initramfs ignorowany), dm-verity, Instalator sprawdza odcisk i podpis | TPM (M10) |
