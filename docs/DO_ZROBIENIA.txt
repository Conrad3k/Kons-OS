2. ZALEGŁOŚCI I RZECZY PRZEKROJOWE
----------------------------------
[ ] Prawdziwy sprzęt (potrzebne do testów na laptopie):
      - start z pendrive'a przez UEFI,
      - grafika z firmware (simpledrm) zamiast karty QEMU,
      - klawiatura i mysz USB, touchpad (I2C-HID),
      - dyski NVMe / SATA.
[ ] Komunikat o błędzie startu widoczny na ekranie (dziś tylko na porcie szeregowym).
[ ] Własny build biblioteki musl 1.2.5 z poprawkami bezpieczeństwa (dziś 1.2.4 z Ubuntu).
[ ] Ochrona _FORTIFY_SOURCE dla programów K1 (decyzja w M3).
[ ] Podłączanie klawiatury/myszy w trakcie pracy (hotplug) i polski układ klawiatury (przy M4).
[ ] Restart usług po awarii (M3) — dziś awaria ekranu nie wyłącza systemu, ale ekran nie wraca.


3. ETAPY
--------
M3  Trusted Core — NASTĘPNY
    [ ] prawdziwy nadzorca: każda usługa z osobnym użytkownikiem (UID/GID) i minimum uprawnień
    [ ] blokada podnoszenia uprawnień (PR_SET_NO_NEW_PRIVS)
    [ ] seccomp: każda usługa może wołać tylko potrzebne funkcje jądra (biała lista)
    [ ] Landlock: każda usługa widzi tylko swoje pliki i urządzenia
    [ ] cgroups v2: limity pamięci i liczby procesów
    [ ] restart ekranu (i później GUI) po awarii, reguły restartów
    [ ] kanały między usługami z kontrolą nadawcy (gniazda UNIX, SO_PEERCRED)
    [ ] testy negatywne: próba podniesienia uprawnień, ucieczki z „klatki”, zabronione wywołania

M4  GUI
    [ ] proces gui: pulpit, okna, pasek (wygląd wg Twoich decyzji z punktu 1)
    [ ] tekst: czcionka i jej rysowanie (z polskimi znakami)
    [ ] okna rysowane w pamięci współdzielonej, składane przez ekran
    [ ] pierwsze aplikacje natywne: zegar, notatki
    [ ] przejęcie gui nie daje dostępu do danych ani systemu (testy)

M5  Blob Vault i szyfrowanie danych
    [ ] magazyn obiektów zamiast katalogów (identyfikator, metadane, hash, pochodzenie)
    [ ] szyfrowanie /dane_uzytkownika na dysku (dziś dane są tylko w RAM)
    [ ] dostęp aplikacji tylko do obiektów, na które się zgodzisz

M6  Dekodery w izolacji
    [ ] każdy plik (np. PNG) dekodowany w jednorazowym, zamkniętym procesie
    [ ] tapeta z pliku PNG przez taki dekoder; testy złośliwymi plikami

M7  Sieć i strefa zgodności (zaplecze A)
    [ ] usługa sieci: Ethernet + DHCP
    [ ] „równoległy Linux” dla obcych programów w izolacji (namespaces, seccomp, Landlock)
    [ ] prosta aplikacja testowa ze strefy wyświetlana w K1

M8  Przeglądarka w strefie
    [ ] wybór: Firefox czy WPE WebKit
    [ ] osobne, jednorazowe sesje (sesje wg Twoich decyzji z punktu 1)

M9  Gatekeeper
    [ ] pobieranie plików, okno zgody, import do Blob Vault, sprzątanie

M10 Bezpieczny start
    [ ] dm-verity: system wykrywa podmieniony obraz
    [ ] Secure Boot z własnymi kluczami, podpisane obrazy, ochrona przed starszą wersją
    [ ] aktualizacje A/B z powrotem do poprzedniej wersji, tryb ratunkowy (recovery)

M11 Mikro-maszyna wirtualna dla przeglądarki (zaplecze B)
    [ ] przeglądarka z własnym jądrem — luka w nim nie daje dostępu do K1 (wymaga KVM)

M12 Audyt
    [ ] fuzzing, testy penetracyjne i izolacji, analiza statyczna, dokumentacja końcowa
